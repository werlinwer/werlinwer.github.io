法律資訊、隱私與製作名單

非官方粉絲遊戲

Pokémon Survivors 是由 Pedro Barretto 製作、由粉絲為粉絲打造的非官方粉絲遊戲。遊戲免費遊玩；可選購的寶石只販售外觀道具，用來支付伺服器與開發費用。

本遊戲與 Nintendo、The Pokémon Company、GAME FREAK inc.、Creatures Inc. 或 Spike Chunsoft 無關，也未經其背書、贊助或核准。

Pokémon 及寶可夢角色名稱是 Nintendo 的商標。Pokémon © Nintendo、Creatures Inc. 與 GAME FREAK inc.。其他所有商標皆屬於其各自的擁有者。

免費、無廣告

遊戲是免費的，也會一直免費：沒有廣告，任何會影響對局或排行榜的東西都不用花錢。唯一能購買的是可選的寶石，用來換造型（見下方）。

寶可夢幣（₽）只存在於遊戲中，無法用真實金錢購買。

如果你願意，可以在「贊助本專案」頁面捐款。捐款是自願的，而且只有在有帳號時才會帶來外觀類的謝禮（稱號、卡片外框、徽章、自選的異色寶可夢、一隻同伴），不會改變對局或排行榜。

寶石

寶石是遊戲的虛擬物品：只能購買外觀道具（例如帽子、拖尾和稱號），會出現在對局、合作模式和競技場中，絕不會影響對戰或排行榜。寶石沒有現金價值，不能兌換成金錢，也不能轉移到其他帳號，只綁定在你的遊戲帳號上。

你可以透過遊玩（每天第一場 5 分鐘以上的對局、同一週玩滿五天，以及競技場，每日有上限）、在 Patreon 上贊助或購買寶石包來獲得寶石。每個帳號每天最多購買 R$ 250 或 US$ 50 的寶石包，未滿 18 歲的玩家需取得父母或監護人的同意才能購買。寶石包透過 Stripe（信用卡、Apple Pay 和 Google Pay）或 AbacatePay（Pix）付款，付款資料直接交給他們：遊戲永遠看不到你的卡片。

退貨權：購買寶石包後 7 天內，你可以申請退還該寶石包中尚未使用的寶石（巴西消費者保護法第 49 條）。請附上購買編號，寄信至 pedro@wavyia.com.br 申請。已使用的寶石以及用寶石購買的外觀道具不予退款。

付款被撤銷或爭議（chargeback）時，會從帳號中扣除該寶石包的寶石，包括已使用的部分。餘額可能變成負數，在餘額為負時無法用寶石購買任何東西。

隱私

預設以訪客身分遊玩，不需要註冊：遊戲沒有 Cookie 或廣告，也從不要求你的姓名或電子郵件等個人資料。

遊戲記住的一切都存在你瀏覽器的 localStorage 中，也就是你的裝置上。以訪客身分遊玩時，這些資料都不會傳送到任何伺服器，只有 ph_ps 中的隨機 ID 例外，它會隨使用統計一起傳送（見下方）：

ps:save
寶可夢幣、在 Kecleon商店購買的強化、遊戲內的寶可夢圖鑑（看過的種類、擊敗的數量與收服了哪些）、孵化器中的蛋（eggs）、孵化的寶可夢（hatched）、任務進度、成就、紀錄（例如擊敗的寶可夢數量與最長存活時間），以及你選擇的稱號。
ps:settings
設定：音樂與音效音量、聲音開關、傷害數字與畫面震動。
ps:lang
你的語言（繁體中文、英文、葡萄牙文、西班牙文或法文）。
ps:muted
只在你玩過舊版本時存在：設定功能推出前的靜音標記。遊戲只會讀取，不再寫入。
ps:account
只在你登入時存在：這台裝置上登入的是哪個帳號（帳號 ID、你的名稱與使用者名稱），以及最後一次同步的進度版本。
ps:runs
只在有帳號時存在：尚未送達排行榜的對局結果（例如離線時）。伺服器收到後就會刪除。
ph_ps
這台裝置的隨機 ID，PostHog 用它來計算對局次數與錯誤（見下方）。它不會透露你是誰。

帳號是選用的，會把你的進度保存在雲端，讓你可以在其他裝置上繼續玩。登入使用 Google，由 Clerk（clerk.com）處理，Clerk 會從 Google 取得你的名稱、電子郵件與大頭貼，並使用自己的 Cookie 讓你保持登入。遊戲永遠看不到你的密碼。

有帳號時，ps:save 的副本會保存在我們的伺服器上，與你的帳號 ID 綁定。它會在你登入時、開啟遊戲時與每場對局結束時傳送。我們的伺服器會保存帳號 ID、你的進度、建立與最後使用的時間，以及排行榜所需的資料（見下方），但不會保存你的電子郵件。

有帳號時，每場對局也會進入排行榜：寶可夢、難度、存活時間、等級、擊敗的敵人數、是否獲勝與遊戲版本，以及對局開始與結束的時間，並與你的帳號 ID 綁定。訪客的對局永遠不會進入排行榜。對局的重播（其種子與你的輸入，不含個人資料）會一併傳送，伺服器可能會重新播放以驗證結果。驗證完成後，或伺服器決定不驗證該場對局時，重播就會被刪除。

你的個人檔案是公開的。登入時，你會選擇一個顯示名稱與一個獨一無二的使用者名稱，後者會出現在個人檔案的連結中。任何人，不論有沒有帳號，都能在排行榜與你的個人檔案上看到：這兩個名稱、你裝備的稱號、各難度的紀錄、寶可夢圖鑑進度、最近的對局，以及追蹤你和你追蹤的人數。你的電子郵件與大頭貼永遠不會顯示。你追蹤了誰、誰追蹤了你會保存在伺服器上；個人檔案只會顯示人數。

登出後，你的進度仍會保留在這台裝置上。若要刪除你的帳號、個人檔案、排行榜對局與帳號中保存的進度，請透過下方的聯絡方式提出。

若要刪除這些資料，請在瀏覽器設定中清除網站資料。

圖像、聲音與字型都由本站提供，不會呼叫第三方服務。本站架設在 Vercel 上，和所有網頁伺服器一樣，Vercel 可能會記錄技術性的存取資料（例如 IP 位址），以運作並保護服務。

遊戲中我們使用 PostHog（posthog.com，資料儲存在美國）來了解遊戲的遊玩方式並修正錯誤。它會收到每場對局的摘要（寶可夢、難度、招式、道具、到達的分鐘數與等級，以及結束方式）、你開啟了哪些選單畫面，以及遊戲發生錯誤時的錯誤訊息與進行中對局的重播（其種子與你的輸入，不含個人資料）。這些全都與 ph_ps 中的隨機 ID 綁定，若你已登入，也會與你的帳號 ID 及使用者名稱綁定，但絕不會與你的電子郵件或姓名綁定。PostHog 在這裡不使用 Cookie，也不會跨網站追蹤你。

捐款是在 AbacatePay（abacatepay.com：Pix 與巴西信用卡）或 Stripe（stripe.com：其他國家的信用卡、Apple Pay 與 Google Pay）的頁面上付款。你的付款資料會直接交給他們，遊戲永遠看不到你的卡片資料。他們會告訴我們金額，以及（就像對任何收款方一樣）付款人的資料（例如姓名與電子郵件），我們只用來記錄這筆捐款。如果你提供了 @（或兌換了捐款的兌換碼），它會與該遊戲帳號綁定，讓獎勵能送達；金額永遠不會公開顯示，只會顯示贊助者徽章，而且你可以隱藏它。
