Vous faites des vidéos du jeu ?

Gameplay, live, guide, Short ou TikTok, dans n’importe quelle langue : chaque vidéo du jeu peut figurer ici.

  1. Publiez votre vidéo sur YouTube, TikTok ou ailleurs.
  2. Partagez le lien dans le salon #screenshots-and-clips de notre Discord.
  3. Donnez-nous votre @ dans le jeu : vous recevez le titre Créateur de contenu et le cadre de créateur.
